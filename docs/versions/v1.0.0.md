# v1.0.0 · 首次归档：雇员工时、喂食续期与保安补充体力

版本开发记录日期：2026年11月8日，北京时间。验证目标：时光餐厅2.0.0。

## 本版内容

- 提供按天或小时设置雇员工作时长，支持小数，范围1分钟至3650天。
- 开启自定义时长后，新雇员的体力和剩余雇期同步采用设定值；现有员工需手动批量应用并再次确认。
- 使用原版食物恢复体力时，可按实际恢复的时长同步延长雇期。
- 为保安开放原版五种食物补充入口，价格、恢复比例和饱腹检查沿用原版流程。
- 使用固定原创暖心时钟入口，放在右上角“我的餐厅”左侧；与已有模组按顺序排列。
- 保存用户设置；批量重设人员时间前记录原数据。

## 默认行为与限制

本版保安喂食默认开启；开启时会隐藏保安能力说明，批量人数合并显示。该历史行为已在后续版本调整。本版尚无菜品补充功能。

保存设置和切换开关不会自动重设现有员工。批量重设会从执行时刻重新计算，较短的设置可能缩短剩余时间。停用模组不会自动恢复已保存的员工到期时间。

保留历史原图，可能超过工坊预览上传体积限制；本归档用于指定旧版手动安装，日常使用推荐工坊最新版。

## 验证范围

原版本留存记录包括34项员工规则检查、对应游戏接口检查及界面验证。档案以当时的验证范围为准，本次整理没有重新进行全部实机操作。
