# v1.1.2 · 修复界面异常粗黑字体

发布日期：2026年11月9日，北京时间。适用验证目标：Windows版时光餐厅2.0.0，游戏构建编号26431062。

## 问题与变化

部分加载顺序下，模组界面会借用游戏标题的粗描边文字材质，导致整页文字显得又粗又黑。此版改用普通正文字体和模组独立材质，避免继承该标题预设。

- 修复工坊版界面文字异常粗黑、描边过厚的问题。
- 优先选用普通正文字体，为模组创建独立材质，清除额外字面扩张、描边、阴影和发光，避免继承游戏标题样式。
- 普通正文和按钮统一使用常规字重，保留页签、开关和禁用按钮的状态颜色。
- 保留暖心餐钟图标、现有设置及工时、喂食、补菜和收费规则。
- 少量报错、日志和编译完成提示中的旧名称统一为“餐厅管家”。

## 升级与安装

首选[Steam创意工坊订阅](https://steamcommunity.com/sharedfiles/filedetails/?id=3836622282)，等待更新完成后完整重启游戏；已运行的游戏不会自动重新加载程序。已有设置继续读取，无需删除设置文件。全新安装且没有旧设置时，四个功能开关仍全部默认关闭。

备选：[本版安装包与校验文件](https://github.com/SiH-zh/Time-Restaurant-Manager/releases/tag/v1.1.2)。正常退出游戏后，解压`EmployeeCare-v1.1.2.zip`，将`EmployeeCare`文件夹放入游戏的`Mods`目录，在主菜单启用。不要同时加载工坊版与手动版。

## 验证结果与边界

已核对工坊下载版、工作版本和发布程序集一致，程序版本1.1.2.0。完整启动日志确认从`steam/3836622282`加载1.1.2；字体日志确认使用`alibaba SDF`独立材质，字面扩张与描边已归零。

已实际打开雇员管理、菜品补充两页，确认标题、正文、输入框与按钮不再出现整页粗黑描边，状态颜色正常。本轮没有执行补菜、扣款、喂食或批量修改人员。完整记录见[验证报告](../../EmployeeCare/验证报告.md)。

工时、喂食、库存和收费业务逻辑沿用1.1.1，少量日志及报错同步统一模组名称；1.1.1已有81项规则检查，本次没有重新运行这些未变更的业务测试。新增置顶余额提示的完整触发交互本轮也未重新验证。
