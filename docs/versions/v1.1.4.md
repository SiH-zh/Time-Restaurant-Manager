# v1.1.4 · 菜槽扩展兼容和原版菜槽恢复

- 原版 9 槽可直接使用补货功能，无需安装菜槽扩展。
- 同时启用「百味食光：菜槽与第三菜系扩展」2.0.1 时，支持给 18 槽布局中已解锁、已上架的菜品补货。主菜、配餐和精品菜继续沿用份数上限、成本检查和余额保护。
- 停用扩展后若存档仍保留 18 槽，完整重启游戏后，在「餐厅管家 → 菜品补充」点击「恢复原版9槽」。查看预览并确认后，可直接用原版菜单补货。

转换会保留原版槽里的菜品和库存，并用同类已解锁的空槽优先保留扩展菜品。原版槽位容纳不下的菜品会在确认前提示，确认后移出售卖菜单，并保存在当前存档目录的 `EmployeeCare/菜槽恢复记录` 清单中供查询。

使用 Windows 版《时光餐厅》构建 `26872895` 的程序集编译，通过 86 项规则检查和 19 项模拟流程检查。本地游戏已确认成功加载 1.1.4，作者实机确认修复可用。发布程序与本机收到的 Steam 创意工坊 1.1.4 程序一致。 [验证报告](../../EmployeeCare/验证报告.md)

优先订阅创意工坊，更新后完整重启游戏。手动安装可下载版本页面的 `EmployeeCare-v1.1.4.zip`，退出游戏后将包里的 `EmployeeCare` 放到游戏 `Mods` 目录，在模组管理中启用本地版。选择一种安装来源即可。 [Steam 创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3836622282) · [1.1.4 安装包和校验文件](https://github.com/SiH-zh/Time-Restaurant-Manager/releases/tag/v1.1.4)
