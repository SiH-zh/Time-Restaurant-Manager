# v1.0.1 · 保安能力说明保留与员工、保安分别计数

版本开发记录日期：2026年11月8日，北京时间。验证目标：时光餐厅2.0.0。

## 本版内容

- 完整保留保安初级／高级能力说明，开启喂食时调整说明位置并自动换行，避免与食物按钮重叠。
- 关闭保安喂食或停用模组时恢复原说明布局。
- 批量设置、二次确认与完成提示分别统计普通员工和保安，例如“10人+1保安”。
- 继续使用固定暖心时钟，不提供图标切换。
- 保留工时设置、实际恢复时长续期及原版食物收费规则。

## 默认行为与限制

本版保安喂食仍默认开启，其他两个功能开关默认关闭；后续版本统一调整初装默认值。本版尚无菜品补充功能。

保存设置和切换开关不会自动重设现有员工。批量重设会从执行时刻重新计算，较短的设置可能缩短剩余时间。停用模组不会自动恢复已保存的员工到期时间。

保留历史原图，可能超过工坊预览上传体积限制；本归档用于指定旧版手动安装，日常使用推荐工坊最新版。

## 验证范围

原版本留存记录包括34项员工规则检查、对应游戏接口检查及界面验证。档案以当时的验证范围为准，本次整理没有重新进行全部实机操作。
