# 编译说明

日常使用优先订阅Steam创意工坊；需要指定旧版时下载版本安装包，无需自行编译。

源码构建需要Windows、本机已安装的《时光餐厅》及游戏自带的程序集。使用Windows PowerShell运行：

```powershell
.\EmployeeCare\Source\编译.ps1 -GameRoot 'D:\SteamLibrary\steamapps\common\时光餐厅'
```

将游戏路径替换为自己的安装位置。脚本调用系统提供的编译器，并引用该游戏安装目录的程序集；输出为 `EmployeeCare/EmployeeCare.dll`。游戏与第三方程序集不分发。

完整源码、程序版本与安装包应使用同一标签。更新程序前正常保存并退出游戏，替换后完整重启。
