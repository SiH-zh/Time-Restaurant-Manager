# 时光餐厅 · 雇员关怀

**当前快照：1.0.1 · 历史版本归档**

保安能力说明保留与员工、保安分别计数。本页对应留存历史版本，日常安装推荐[Steam创意工坊最新版](https://steamcommunity.com/sharedfiles/filedetails/?id=3836622282)；需要旧版时使用[本版安装包](https://github.com/SiH-zh/Time-Restaurant-Manager/releases/tag/v1.0.1)。

## 功能与默认行为

- 完整保留保安初级／高级能力说明，开启喂食时调整说明位置并自动换行，避免与食物按钮重叠。
- 关闭保安喂食或停用模组时恢复原说明布局。
- 批量设置、二次确认与完成提示分别统计普通员工和保安，例如“10人+1保安”。
- 继续使用固定暖心时钟，不提供图标切换。
- 保留工时设置、实际恢复时长续期及原版食物收费规则。

本版保安喂食仍默认开启，其他两个功能开关默认关闭；后续版本统一调整初装默认值。本版尚无菜品补充功能。

## 安装

正常保存并退出游戏，解压安装包，将 `EmployeeCare` 文件夹放入游戏的 `Mods` 下，在主菜单启用并重启。历史版名称为“雇员关怀：工时与喂食续期”，入口为右上角暖心时钟。请勿同时安装同一模组的工坊版与手动版。

保存时长不会自动重设现有人员，批量应用需再次确认；较短的时长可能缩短原剩余时间。停用不会自动撤回已保存的到期时间。
