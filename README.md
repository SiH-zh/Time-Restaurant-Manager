# 时光餐厅 · 雇员关怀

**当前快照：1.0.0 · 历史版本归档**

首次归档：雇员工时、喂食续期与保安补充体力。本页对应留存历史版本，日常安装推荐[Steam创意工坊最新版](https://steamcommunity.com/sharedfiles/filedetails/?id=3836622282)；需要旧版时使用[本版安装包](https://github.com/SiH-zh/Time-Restaurant-Manager/releases/tag/v1.0.0)。

## 功能与默认行为

- 提供按天或小时设置雇员工作时长，支持小数，范围1分钟至3650天。
- 开启自定义时长后，新雇员的体力和剩余雇期同步采用设定值；现有员工需手动批量应用并再次确认。
- 使用原版食物恢复体力时，可按实际恢复的时长同步延长雇期。
- 为保安开放原版五种食物补充入口，价格、恢复比例和饱腹检查沿用原版流程。
- 使用固定原创暖心时钟入口，放在右上角“我的餐厅”左侧；与已有模组按顺序排列。
- 保存用户设置；批量重设人员时间前记录原数据。

本版保安喂食默认开启；开启时会隐藏保安能力说明，批量人数合并显示。该历史行为已在后续版本调整。本版尚无菜品补充功能。

## 安装

正常保存并退出游戏，解压安装包，将 `EmployeeCare` 文件夹放入游戏的 `Mods` 下，在主菜单启用并重启。历史版名称为“雇员关怀：工时与喂食续期”，入口为右上角暖心时钟。请勿同时安装同一模组的工坊版与手动版。

保存时长不会自动重设现有人员，批量应用需再次确认；较短的时长可能缩短原剩余时间。停用不会自动撤回已保存的到期时间。
