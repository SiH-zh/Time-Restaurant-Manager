# 时光餐厅 · 餐厅管家

《时光餐厅》的非官方功能模组，将雇员工作时长、喂食续期、保安体力补充和在售菜品补充放在同一个设置面板，方便提前安排员工工作与营业库存。

**当前版本：1.1.2** · [Steam创意工坊订阅（推荐）](https://steamcommunity.com/sharedfiles/filedetails/?id=3836622282) · [GitHub手动下载（备选）](https://github.com/SiH-zh/Time-Restaurant-Manager/releases/tag/v1.1.2) · [历史版本](https://github.com/SiH-zh/Time-Restaurant-Manager/releases) · [游戏Steam商店](https://store.steampowered.com/app/4399360/?l=schinese) · [MIT许可证中文对照](LICENSE.zh-CN.md)

日常使用优先订阅工坊版；GitHub提供源码、完整版本记录和备选手动安装包。旧版本使用“雇员关怀”名称，当前统一显示“餐厅管家”，内部目录仍为 `EmployeeCare`，升级保留原设置。

## 功能

| 功能 | 使用方式 |
| --- | --- |
| 自定义工作时长 | 按天或小时设置，支持小数，范围1分钟至3650天；同步设置体力和剩余雇期，包括保安。 |
| 现有人员批量应用 | 手动应用并再次确认，普通员工与保安分别统计，例如“10人+1保安”。 |
| 喂食同步续期 | 按实际恢复的体力时长延长雇期，食物价格、比例和满体力限制沿用原版规则。 |
| 保安补充体力 | 显示原版五种食物，完整保留初级／高级保安能力说明。 |
| 在售菜品补充 | 主菜、配餐、精品菜一起补充，提供+10、+100、+1000、+10000和纯整数自定义输入。 |
| 按成本扣金币 | 可免费补充，也可按原版单份成本收费；余额不足整次取消，显示金额、余额和差额。 |

## 安装与更新

### 首选：Steam创意工坊订阅安装（推荐）

1. 完整退出游戏，打开[餐厅管家创意工坊页面](https://steamcommunity.com/sharedfiles/filedetails/?id=3836622282)并点击“订阅”。
2. 等待Steam下载完成，再启动游戏。
3. 在主菜单的“模组”中勾选“餐厅管家：雇员管理与菜品补充”，按游戏提示完成启用并重启。
4. 进入自己的餐厅，点击右上角、“我的餐厅”左侧的暖心餐钟入口。

工坊版由Steam管理下载与后续更新，更新后需完整重启游戏加载代码。若之前手动安装过，请先退出游戏，将原 `Mods/EmployeeCare` 目录移到 `Mods` 之外备份，避免同一模组重复加载；用户设置可以保留。

### 备选：GitHub手动下载安装

需要指定历史版本，或无法通过工坊安装时，使用[GitHub版本发布](https://github.com/SiH-zh/Time-Restaurant-Manager/releases)。

1. 完整退出游戏；若已订阅工坊版，先取消订阅，保持一个安装来源。
2. 下载 `EmployeeCare-v版本号.zip` 安装包，日常使用无需下载GitHub自动生成的源码压缩包。
3. 解压后将整个 `EmployeeCare` 文件夹放入游戏目录的 `Mods` 文件夹。
4. 启动游戏，在主菜单的“模组”中启用。更换程序文件后需完整重启游戏。

正确位置：`游戏目录/Mods/EmployeeCare/EmployeeCare.dll`。手动更新前备份旧目录，备份放在 `Mods` 之外。

设置独立保存于 `UserData/Current/EmployeeCare/settings.json`。正常升级和切换安装渠道无需删除该文件，回退旧版前建议另行备份。


## 快速使用

进入自己的餐厅，点击右上角、“我的餐厅”左侧的暖心餐钟图标。已有其他模组按钮时，本入口继续向左排列。

- **雇员管理**：输入时长、选择天或小时并保存，按需启用。新雇员使用设定时长；现有人员需另行点击批量应用并再次确认。
- **喂食续期与保安喂食**：分别开关。续期只计算实际恢复的时长，满体力或恢复失败不续期。
- **菜品补充**：快捷按钮会立即给每道已上架菜增加标注份数；也可输入份数后点击手动补充。收费方式由独立开关决定。

全新安装且没有旧设置时，**四个开关全部默认关闭**。工作时长预设30天，补货输入初始1000；预设数字不会自动执行任何批量操作。设置会保存，重启恢复；已有用户升级保留原设置。

页签选中与功能开启时为绿色，未选中与关闭时为黄色；开关同时显示文字状态，不可用按钮变暗。完整操作见[使用说明](EmployeeCare/使用说明.md)。

## 菜品份数与金币

补充只作用于当前已上架、已解锁的菜槽，包括已上架但售罄的菜。空槽不自动上菜。

例如3道主菜、3道配餐、1道精品菜，点击“+1000”会**每道各加1000份，合计7000份**。每次每道最多增加10万份，每道补充后库存最多100万份。拒绝小数、负数、科学计数法、分隔符、空格和超大数字；任意一道超过安全值则整次取消。

收费关闭时免费补充；开启后费用为“各参与菜槽的单份金币成本之和 × 每道增加份数”，使用游戏成本资料，不按售价扣钱。点击时再次核对余额，**不足时不扣金币、不补充任何菜品**。金额乘法和求和包含溢出检查。

这是一次性增加实际库存，允许超过原版单槽购买容量；库存会保存并正常售卖消耗，没有自动补货或无限库存。

## 数据保存与适用范围

员工批量重设及菜品补充前会将相关原记录写入 `UserData/Current/EmployeeCare/Backups`。这些是字段清单，**不是完整存档备份**。保存时长、切换开关不会自动重设现有员工；批量重设从执行时刻计算，较短的设置可能缩短剩余时间。

停用模组不会自动撤回已经保存的库存和员工到期时间。如需恢复整份存档，需退出游戏后恢复备份，备份之后的其他进度也会回退。

只处理自己餐厅实际雇用的厨师、服务员和保安，永久超级员工除外。做客、装修、扩建预览与存档冻结期间不补货。工时通过目标到期时间反算原雇佣开始时间实现，长时长下底层开始日期可能位于未来，剩余时间正常倒计时。

已验证目标为Windows版时光餐厅2.0.0，本机游戏构建编号 `26431062`。游戏更新或其他模组修改相同逻辑时可能需要适配，不承诺兼容所有组合。既有81项业务规则检查见[1.1.1版本详情](docs/versions/v1.1.1.md)。1.1.2已确认从工坊加载，雇员管理与菜品补充两页字体正常，详见[字体修复与验证](docs/versions/v1.1.2.md)。新增置顶余额提示的完整触发交互尚未重新实机验证。
