# 时光餐厅 · 雇员关怀

**当前快照：1.0.2 · 历史版本归档**

全新安装功能开关默认关闭。本页对应留存历史版本，日常安装推荐[Steam创意工坊最新版](https://steamcommunity.com/sharedfiles/filedetails/?id=3836622282)；需要旧版时使用[本版安装包](https://github.com/SiH-zh/Time-Restaurant-Manager/releases/tag/v1.0.2)。

## 功能与默认行为

- 全新安装且没有旧设置时，自定义工作时长、喂食同步延长雇期、保安食物补充均默认关闭。
- 工作时长仍预设为30天，需用户主动开启后才用于新雇员。
- 已有用户升级继续读取原开关、时长和显示单位，不强制重置。
- 保留保安原有能力说明、员工与保安分别计数及固定图标。

全新安装三个功能开关均关闭，已有设置保留。本版尚无菜品补充功能。

## 安装

正常保存并退出游戏，解压安装包，将 `EmployeeCare` 文件夹放入游戏的 `Mods` 下，在主菜单启用并重启。历史版名称为“雇员关怀：工时与喂食续期”，入口为右上角暖心时钟。请勿同时安装同一模组的工坊版与手动版。

保存时长不会自动重设现有人员，批量应用需再次确认；较短的时长可能缩短原剩余时间。停用不会自动撤回已保存的到期时间。
